# What-if / Negotiation Simulator

Evaluates how freight and operating-cost changes affect trip economics.

## Inputs

- current_freight
- total_cost
- target_margin
- scenario_rates

## Outputs

- break_even_freight
- minimum_acceptable_freight
- recommended_target_freight
- expected_profit
- expected_margin
- scenario table

The tool should answer questions such as:

- What rate gives me a 15% margin?
- What happens if fuel rises by ₹5/L?
- What happens if the customer offers ₹2,000 less?

Recommendations: ACCEPT, NEGOTIATE, REJECT.
